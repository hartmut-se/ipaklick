IPAKLICK

This is a tool for inserting phonetic symbols into electronic documents. IPAKLICK was first placed on the Web through the Department of Linguistics at Stockholm University on 2003-09-15. This repository contains the revised version of IPAKLICK of 2026-10-15 and provides its current public home.

Use of the tool requires the presence of phonetic fonts. The list below is from 2003, when some deficiencies in the listed fonts were noted.

  • Arial Unicode MS (present in certain Microsoft systems)1
  • Dialekt Uni (free download)1, 2
  • SIL Gentium (free non-commercial download)2
  • Lucida Sans Unicode (present in most Microsoft systems)1, 2
  • SILDoulosUnicodeIPA (free download)1, 2
  • TITUS Cyberbit Basic (free non-commercial download)1, 3
1This font suffered from deficiencies in details.
2 This font lacked one or several symbols.
3 This font misplaced the syllabicity mark after the basic character.

Note: The arrangement of the open vowels [æ ɶ a ɑ ɒ] in IPAKLICK represents an improvement of their conventional arrangement by the International Phonetic Association.

Instructions for use

  1. Use your keyboard or click the IPA symbols you want to appear in the text window of IPAKLICK. Diacritics (highlighted) are to be inserted after the basic character, double diacritics after their first basic character.
  2. Copy or cut out the symbol string from the text window and paste it where you want it.
  3. For more information about a symbol, you can copy it for a search in Wikipedia or on the Web.

This tool is free to use and share.
